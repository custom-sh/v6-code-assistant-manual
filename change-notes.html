当前插件版本 v1.2.6

更新日志

版本记录

Version 1.2.6

Added

  • 项目配置新增可选「PAD（平板端）」模块：支持配置项目路径与应用端口，并显示平台/项目版本标签；PAD 为可选端，留空不影响配置、初始化、升级和构建。
  • 「一键初始模板」支持 PAD 端：重命名 demo 视图目录为项目编码、执行 npm install 并替换残留 demo 占位符。
  • 「升级版本」支持 PAD 端：修订版本升级替换平台包并更新 package.json，大版本升级全量替换且支持勾选备份保留二开目录。
  • 「构建项目」支持 PAD 端：构建后打包 dist 为 pad.zip，项目版本号统一写入包含 PAD 在内的各端。
  • 版本一致性检查纳入 PAD 端：跨端平台/项目版本对比，以及 PAD 内部平台包版本一致性检查。

Version 1.2.5

Changed

  • 优化V6开发手册AI问答。
  • 二开菜单导入改为幂等处理 XxRun.java 注册：已注册时不再阻止导入，并在预览中显示“已注册，无需修改”。

Version 1.2.4

Fixed

  • 优化一些问题。

Version 1.2.3

Fixed

  • 修复一键二开代码相关转换问题。

Version 1.2.2

Added

  • AI 助手支持通过自然语言查询平台二开功能，可按功能名称或菜单编码匹配并展示候选菜单。
  • AI 对话新增当前项目源码上下文，可自动检索相关代码片段。
  • 二开菜单列表支持识别 Web、PDA、PAD 端类型；可导入功能支持预览转换，不可导入功能支持查看完整平台源码。
  • 平台源码库支持扫描自定义源码根目录，并自动解析其中的二开功能。（一般配置为对应版本的二开源码包路径：E:\svn\publish-source\v6.8.0）
  • 一键二开扩展支持标准 Model Web、无 Model Web 和 PDA 功能，自动转换相关 Model、Controller、Service、Vue、菜单及运行注册代码。
  • 一键二开支持创建或加载 ImsMenuScript.java，通过 AI 追加平台禁用菜单编码；AI 不可用时提示人工处理。
  • 二开菜单导入预览新增源码变更行标记：新增行显示绿色标记，修改行显示蓝色标记；已有目标文件可使用 IDEA 原生差异窗口查看修改。

Changed

  • 功能包外平台组件统一通过 ims-web 的 systempartMap 引用，并合并重复导入。

Fixed

  • 修复 PDA 菜单二开时菜单类型字面量 "i" 未转换为 CoreColumnType.MenuType.MENU_ITEM 的问题。

Version 1.2.1

Added

  • 新增“二开菜单列表”：支持查询、转换并导入，自动处理菜单、URL、注册等项目要求。（当前仅支持标准Model功能，即前端菜单能看到源码的菜单）
  • 项目配置新增“平台源码库（可选SVN二开源码库）”，自动解析结果并入“二开菜单列表” 。
  • 代码扫描新增“仅扫描当前 SVN 用户修改的行”范围，支持确认项目 SVN 账号并根据行级修改人过滤扫描结果。
  • 支持选择代码基于开发手册进行问答，解释代码。

Changed

  • 重构开发手册问答，中文问题或流式回答出现乱码的问题；支持代码解释、关联代码
  • 扩展版权注释创建者解析，兼容创建日期与“创建”之间无空格、连接符数量不同的格式。
  • 扩展事务注解扫描规则：业务事务要求使用 @MasterTransactional，查询库事务允许显式指定 queryTransactionManager。
  • 设置窗口最小宽度根据项目配置页面所需宽度自动调整，避免路径、端口和版本信息被挤压。

Fixed

  • 修复“构建项目”在中文路径下通过临时批处理和多层 CMD 启动时出现路径乱码的问题。

Version 1.2.0

Added

  • 代码扫描器：支持按代码创建者扫描
  • 初始化模板支持 CS 端项目；平台升级和项目构建暂不包含 ims_client（CS 端）。
  • 转义字段翻译命名、内置手册问答 统一接入 AI配置中供应商；重构 AI 配置界面，提供 OpenAI、Anthropic、DeepSeek 及常用兼容供应商预设。

Changed

  • 代码扫描历史代码豁免（截止日期暂定 2026-05-25）：关闭项目模式后，版权注释中创建日期早于截止日期的文件， 跳过类名规范、主键/唯一约束/普通索引命名、复合索引 org_code 末位检查，以及 PDA 表单 FormComponentHandler.build() 链式调用中冗余的 setLabel()/setName() 检查。
  • 代码扫描规则：关闭项目模式后跳过“栏位编码须以项目编码开头”规则。
  • 代码扫描规则：标准 Java public static void main(String[]/String...) 入口方法允许使用 System.out/err 输出；非标准 main 及其他普通方法仍正常检查。
  • 代码扫描规则：类名为 ImsSelectorDml 的类跳过“多行 SQL 必须存在 @formatter 标识”检查。
  • 代码扫描规则：abstract class XxxTable extends Table 可以不加 @DbMetaData
  • 代码扫描规则：实现类中方法 可以不加 @Override
  • 代码扫描规则：版权声明中日期范围调整：2021-至今
  • 数据库驱动按需加载优化：下载前依次检查插件全局 Maven 仓库、IDEA Maven 仓库和默认 ~/.m2/repository，命中后直接复用本地驱动；补充仓库命中、回退及网络下载日志。

Fixed

  • 代码扫描规则：修复“集合初始化需指定容量”规则误报 LinkedList 无参构造的问题。
  • 代码扫描规则：修复 foreach 遍历某对象的集合字段时，向其他对象的同名集合字段执行修改的误报
  • 代码扫描规则：修复非项目模式下，从基础 ColumnDescDef 继承的列描述常量被误报为变量的问题。
  • 代码生成器：修复向 ImsSelectorDml 追加选择器时缺少块间空行、表名注释缩进丢失及 CRLF 文件出现混合换行的问题。
  • 修复部分场景下全局配置未回显 Maven 信息的问题；插件配置为空或读取失败时，回退展示 IDEA 计算出的有效 Maven 配置。
